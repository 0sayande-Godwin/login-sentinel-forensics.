# Login Sentinel Forensics

## Project Description

Login Sentinel Forensics is a simple Python program that helps analyze login data to detect any fraudulent login attempts.

The program analyzes security logs, detects failed login attempts, checks if there is any repetition of login attempts from an IP address, and records the suspicious behavior for investigation.

## Program Features

- Detecting failed login attempts
- Checking for repeated login attempts from an IP address
- Logging suspicious login activities
- Basic IP blocking
- Generating data for security investigations
- Using Python to analyze the logs

## Technologies Used

- GitHub
- VS Code
- Analyzing log files
